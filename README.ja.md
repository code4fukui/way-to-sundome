# way-to-sundome
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

日本語のWebアプリケーションで、マップ上にSundomeへのルートを表示します。

## デモ
デモは[https://digitaltwin-echizen.github.io/way-to-sundome/](https://digitaltwin-echizen.github.io/way-to-sundome/)で利用可能です。

## 機能
- Sundome への経路をマップに表示します
- ユーザーが自身の現在位置をマップ上で追跡できるモードを切り替えられます

## 要件
このプロジェクトは以下のライブラリを使用します:
- [Leaflet.js](https://leafletjs.com/)
- [Geo3x3](https://geo3x3.com/)
- [CSV.js](https://github.com/code4sabae/CSV.js)
- [QR Code](https://code4fukui.github.io/qr-code/)
- [fetchImage](https://js.sabae.cc/fetchImage.js)

## 使用方法
アプリケーションを実行するには、`index.html`ファイルをWebブラウザーで開いてください。

## データ / API
このプロジェクトは以下のオープンデータソースを使用しています:
- [Aioi Nissay Dowa Insurance のテレマティクスオープンデータ](https://www.aioinissaydowa.co.jp/)
- [Kunitaka District Autonomous Promotion Association のコミュニティ安全オープンデータ](https://www.city.echizen.lg.jp/office/010/130030/kunitaka.html)
- [越前市のストリートライトオープンデータ](http://www.city.echizen.lg.jp/index.html)

# way-to-sundome
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A web application that displays a route to the Sundome on a map.

## Demo
The demo is available at [https://digitaltwin-echizen.github.io/way-to-sundome/](https://digitaltwin-echizen.github.io/way-to-sundome/).

## Features
- Displays a route to the Sundome on a map
- Allows users to toggle a "current location tracking" mode to follow their position on the map

## Requirements
This project uses the following libraries:
- [Leaflet.js](https://leafletjs.com/)
- [Geo3x3](https://geo3x3.com/)
- [CSV.js](https://github.com/code4sabae/CSV.js)
- [QR Code](https://code4fukui.github.io/qr-code/)
- [fetchImage](https://js.sabae.cc/fetchImage.js)

## Usage
To run the application, open the `index.html` file in a web browser.
